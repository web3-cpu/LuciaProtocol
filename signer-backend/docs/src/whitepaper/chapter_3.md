# Chapter 3


## Features

### Show Accessible Accounts

So you want to onboard a new team member? Perhaps they are getting offers from your competitors ten times your size. What's the first things that you'll have to have ready for hiring the best of the best?

* A solid brand which includes published marketing content
* A way for new team members to learn company processes and protocols
* A way to disperse payments

So each of these are considerable. You don't want to make a poor first impression - it's the only one you've got. Delegation is key to scalability so you'll want to be able to delegate quickly. My standard for success is to have a new secretary be able to make a valuable contributions on day one. 


### Technical Features


Let's say there is an interface that can be created. You have a function for creating a list of all applicable candidates. What's even better? You have a way to get performance metrics on each of those list items. Instead of creating thousands of training modules, certification courses, etc - you have a way to train new team members in real time. 

So the thesis of this concept: _in order for businesses to be successful, each team member will be trained to take accountability for their work within their roles and responsibilities._
