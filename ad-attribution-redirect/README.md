# ad-attribution-redirect

commands to run:

1. npm -i (To install all modules)
2. Create a .env file with the backend_url: eg - BACKEND_URL = 'http://localhost:3001'
3. node app.js
4. http://localhost:3001/
5. run `cp .env.example .env`

These commands will run the simple redirect project on port 3000

The initial commit inlcudes:
redirecting localhost to lucia protocol's website.
This will also log user agent information to the command line while it redirects
